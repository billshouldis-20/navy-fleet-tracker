# Military-inspired logo assets

The UI has optional branded image slots for the fleet header, hierarchy page and deployment branch filter.

Copy the approved exported artwork into this folder. The application uses the following optimized images:

| UI element | Relative path |
|---|---|
| Fleet Command | `navy-128.webp` |
| Hierarchy page | `hierarchy-128.webp` |
| Army deployment filter | `army-128.webp` |
| Navy deployment filter | `navy-128.webp` |
| Marines deployment filter | `marine-corps-128.webp` |
| Air Force deployment filter | `air-force-128.webp` |
| Space Force deployment filter | `space-force-128.webp` |
| Coast Guard (future support) | `coast-guard-128.webp` |

The artwork bundle also contains source PNGs and 256px WebP alternatives. If an image is missing, the UI hides the image instead of displaying a broken-image marker.

These are custom military-inspired emblems, not official U.S. military seals. Do not present them as government-issued insignia.
